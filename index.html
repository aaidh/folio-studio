FROM DRAFT TO LIVE

Your portfolio, out in the world.

The download is a complete index.html website. Your photo, styles, and content are included.

  1. Click Download website and keep the file named index.html.
  2. Create a public GitHub repository and upload that file.
  3. Open Settings → Pages. Choose Deploy from a branch, then main and / (root). Save.
  4. GitHub will show your website link after deployment finishes.

Your draft file is for editing later. Publish the website download, not the draft JSON.
